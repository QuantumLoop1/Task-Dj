🎧 DJ Management API
Минимальное ASP.NET Core Web API для управления диджеями и их треками. Проект реализован с использованием современных практик разработки.

🚀 Функциональность (Endpoints)
API предоставляет следующие endpoints:

GET /api/djs

Получение списка всех диджеев.

Использует: GetAllDJs()

GET /api/djs/{id}

Получение информации о диджее по его идентификатору.

Использует: GetDJById(int id)

POST /api/djs

Добавление нового диджея в систему.

Использует: AddDJ(DJ dj)

GET /api/djs/{djId}/tracks

Получение списка всех треков, принадлежащих конкретному диджею.

Использует: GetTracksByDJId(int djId)

🛠️ Технологии и Практики
В этом проекте были успешно внедрены и использованы ключевые технологии и паттерны современного .NET:

🗂️ Minimal APIs - Для создания чистого и лаконичного кода endpoints.

💉 Внедрение зависимостей (Dependency Injection) - Для управления жизненным циклом сервисов и достижения слабой связанности кода.

Сервисы для работы с данными (DJ, треки) зарегистрированы в DI-контейнере.

📝 Логирование (ILogger) - Встроенная система логирования используется для записи информации о запросах, ошибках и работе приложения.

⚙️ Конфигурация (IOptions) - Настройки приложения (например, строки подключения к БД, внешние API) вынесены в конфигурационные файлы (appsettings.json) и доступны через типизированный подход с IOptions<T>.

🌐 HttpClient - Настроен и используется для взаимодействия с внешними API (например, для получения дополнительной информации о треках или интеграции со стриминговыми сервисами).

📚 Swagger UI - Для интерактивной документации API и тестирования endpoints. Доступен по пути /swagger после запуска приложения.

🏃 Запуск проекта
Убедитесь, что установлен .NET 6 SDK или новее.

Клонируйте репозиторий.

В файле appsettings.json укажите актуальные строки подключения и другие настройки.

Выполните в командной строке из папки проекта:

bash
dotnet run
Откройте браузер и перейдите по адресу https://localhost:<PORT>/swagger (порт указан в выводе консоли).

📁 Структура сервисов
Проект использует сервисный слой для инкапсуляции бизнес-логики:

IDJService - интерфейс, определяющий контракт для работы с диджеями.

DJService - реализация сервиса, содержащая методы:

AddDJ(DJ dj)

IEnumerable<DJ> GetAllDJs()

DJ GetDJById(int id)

IEnumerable<Track> GetTracksByDJId(int djId)
